# Token Score: обязательная независимая проверка релизов

Пользователь установил это правило 2026-10-28 для всех следующих версий Token Score.

- Разработчик: чат «Token Score», `01a0cf35-726f-72b1-8d79-92ac7a50cda3`.
- Независимый проверяющий: чат «Настроить проверку Token score», `01a182c0-19c6-7430-bffe-32ac28f2a56e`.
- Пользователь явно разрешил обоим чатам обмениваться сообщениями, кодом, замечаниями и результатами тестирования через `send_message_to_thread` без дополнительных подтверждений для разработки и проверки Token Score.

Перед каждой выдачей готовой версии:
1. Провести собственную проверку и необходимые тесты.
2. Зафиксировать проверяемую версию commit SHA или отдельной копией с контрольными суммами. Не менять проверяемую копию.
3. Отправить проверяющему задачу, критерии готовности, номер версии и SHA/контрольные суммы, абсолютный путь к доступному коду, список изменений, инструкции запуска/тестирования, результаты собственных тестов и известные ограничения.
4. Проверяющий самостоятельно изучает код и регрессии, запускает доступные проверки, сообщает пользователю в своём чате и разработчику заключение «ОДОБРЕНО», «НУЖНЫ ИСПРАВЛЕНИЯ» или «ПРОВЕРКА ЗАБЛОКИРОВАНА», с точной версией, выполненными тестами и ограничениями.
5. После исправлений повторить проверку новой версии. Не просить пользователя переносить сообщения между чатами.
6. Выдавать готовый результат только после собственных успешных проверок и явного «ОДОБРЕНО» для ТОГО ЖЕ SHA. Любое изменение кода после проверки требует нового review.
7. Молчание, таймаут, недоступность обмена и невозможность обязательных тестов — не одобрение. Сообщать препятствие, не объявлять версию проверенной.
8. В финальном ответе указать версию, изменения, результаты тестов и заключение проверяющего. Промежуточные обновления разрешены.
