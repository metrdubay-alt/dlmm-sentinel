# DLMM Sentinel

Русскоязычное desktop-приложение для исследования токенов и сравнения эффективности пулов. Текущая версия — **0.3.30**. Основная платформа — Windows 10/11 x64.

## Возможности

- Карточка токена по адресу и выбранной сети: Solana, BSC, Ethereum, Base и Robinhood Chain.
- Числовые показатели GMGN: капитализация, холдеры, концентрация, бандлеры, phishing, наблюдатели, Total Fees и объёмы за 5 минут и час. Подсветка значений и правила Runner / Slowcook.
- Анализ X/Twitter через Grok: нарратив, значимые аккаунты, красные и зелёные флаги, оценка 0–100 и ссылки. GetMoni читается отдельно, если доступен.
- Meteora для Solana и GeckoTerminal для остальных сетей: поиск пулов, до 10 лучших с TVL > $1 000, сортировка по Fee/TVL за 5 минут или час.
- Для Meteora DLMM учитываются базовая и динамическая комиссии, Active TVL и Bin.
- Суточный Fee/TVL показывается как линейный пересчёт текущего окна: 5 минут × 288 либо час × 24. Суточные значения округляются до одного знака.
- Независимые кнопки обновления числового анализа, Grok и пулов. Архив карточек с удалением.
- Demo mode с явно обозначенными демо-данными, mock-провайдеры и тестовые сценарии.

Приложение не торгует, не подписывает транзакции и не запрашивает seed phrase или приватный ключ. Fee/TVL — оценка эффективности пула при текущей ставке комиссии, а не фактически полученная доходность позиции. Суточный пересчёт предполагает сохранение темпа.

## Запуск разработки

Нужны Windows x64, Node.js 22.12+ или 24 LTS и npm. Интернет требуется для установки зависимостей и работы реальных источников.

```powershell
git clone https://github.com/metrdubay-alt/dlmm-sentinel.git
cd dlmm-sentinel
npm ci
Copy-Item .env.example .env
npm run prisma:generate
npm run dev
```

Клиент Prisma генерируется локально. Иконки уже включены в репозиторий; пересоздать их можно командой `npm run icons:generate`.

По умолчанию включён демо-режим. Для реальных данных выберите «Реальные источники» и войдите в нужные сервисы через кнопки приложения. Вход в X используется и для Grok. Сессии браузера Codex или обычного браузера не переносятся автоматически в Electron.

Доступность Grok и GetMoni зависит от аккаунта и лимитов сервиса. GMGN, X и GetMoni читаются через встроенные окна; изменения интерфейсов сайтов могут потребовать обновления адаптеров. Публичные данные Meteora и GeckoTerminal не требуют входа; источники могут ограничивать частоту запросов. Недоступные значения не заменяются демо-данными.

## Проверка и сборка

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npx tsx scripts/verify-build.ts
npm run test:e2e
```

Запускайте E2E после сборки. Тесты используют отдельные временные каталоги данных. Для сборки Windows-установщика:

```powershell
npm run dist:win
```

Результат появляется в `release/`. NSIS создаёт ярлыки на рабочем столе и в меню «Пуск». Установщик не подписан сертификатом издателя. Сборки macOS/Linux предусмотрены конфигурацией, но не проверены.

Если генерация Prisma сообщает, что файл занят, закройте запущенный экземпляр приложения или тестовый Electron и повторите команду.

## Структура

| Каталог | Содержание |
| --- | --- |
| `src/main` | Electron, чтение источников, хранение и IPC |
| `src/renderer` | React UI на русском языке |
| `src/shared/analysis` | Схемы данных, правила оценки, расчёты и промпт Grok |
| `src/tests` | Unit, integration и Electron E2E тесты |
| `prisma` | Схема SQLite и миграции |
| `scripts` | Разработка, сборка, демо-база и проверка артефактов |
| `assets`, `build` | Исходник иконки и готовые ресурсы приложения |

Точный промпт Grok находится в `src/shared/analysis/grok.ts`, функция `buildGrokPrompt`. Формула Meteora DLMM в `src/main/services/meteora-pools.ts`: объём × (базовая Fee + Dynamic Fee) / Active TVL. Формула остальных пулов использует общий TVL. Ставки в этих формулах заданы в процентах, поэтому результат также выражен в процентах.

## Локальные данные

SQLite, сессии сервисов и зашифрованные credentials хранятся в профиле приложения, обычно `%APPDATA%\DLMM Sentinel`. Они не входят в репозиторий. Также исключены локальные исследования, выгрузки аккаунтов, Word-документы, установщики и временные диагностические скрипты.

В тестовых данных есть сохранённый публичный ответ GeckoTerminal для проверки обработки минутных свечей. Он используется только как регрессионный пример, не как актуальный рыночный снимок.
